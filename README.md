# 🎙️ PARISA AI — মেমোরি পোর্টাল & ইনভেস্টিগেটিভ আর্কাইভিস্ট

> **"ডেটা হলো সত্য। আবেগ হলো প্রসঙ্গ। আর্কাইভ চিরস্থায়ী।"**

PARISA AI একটি অত্যাধুনিক **মাল্টি-এআই চ্যাট প্ল্যাটফর্ম**, যা বৃহৎ চ্যাট ডেটাবেস, Google Drive ইন্টিগ্রেশন, এবং উন্নত ভয়েস সিন্থেসিস সমন্বিত করে। এটি সম্পর্কের দীর্ঘমেয়াদী ডিজিটাল প্রমাণ সংরক্ষণ এবং আচরণ বিশ্লেষণের জন্য ডিজাইন করা হয়েছে।

---

## ✨ মূল বৈশিষ্ট্য

### 🧠 বুদ্ধিমান চ্যাট ইঞ্জিন
- **মাল্টি-প্রোভাইডার এআই**: Google Gemini, Groq, OpenRouter, DeepSeek এর সমন্বিত সাপোর্ট
- **স্বয়ংক্রিয় ফেইলওভার**: একটি প্রোভাইডার ব্যর্থ হলে স্বয়ংক্রিয়ভাবে পরবর্তীটি চেষ্টা করে
- **API পুল ম্যানেজমেন্ট**: ১০+ API কী সমর্থন করে, স্বয়ংক্রিয় রেট-লিমিট ব্লকিং
- **শূন্য হ্যালুসিনেশন প্রতিশ্রুতি**: শুধুমাত্র ডাটাবেসের সত্য ডেটা ব্যবহার করে

### 📊 গ্লোবাল টাইমলাইন ডাটাবেস
- **৬৮,৪০৭+ মেসেজ**: ১২টি চ্যাট ফাইল জুড়ে সম্পূর্ণ সম্পর্কের ইতিহাস
- **মাল্টি-প্ল্যাটফর্ম আর্কাইভ**: WhatsApp, Facebook Messenger, Telegram, IMO
- **স্মার্ট সার্চ**: তারিখ, বাংলা সংখ্যা, মাস-বছর সহ উন্নত খোঁজার সুবিধা
- **আচরণ পরিসংখ্যান**: স্বয়ংক্রিয় মাসিক বিশ্লেষণ (উষ্ণ ↔ শীতল, যোগাযোগ প্যাটার্ন)

### 🎬 Google Drive ইন্টিগ্রেশন
- **স্ক্রিনশট ভিশন**: Drive ছবিতে থাকা টেক্সট স্বয়ংক্রিয়ভাবে পড়ে এবং বিশ্লেষণ করে
- **মেমোরি ড্যাশবোর্ড**: সাবফোল্ডার সংগঠন (WhatsApp, Messenger, Telegram, IMO)
- **রিয়েল-টাইম সিঙ্ক**: ২-ঘন্টার TTL সহ স্বয়ংক্রিয় ৩০-মিনিটের রিফ্রেশ
- **রিচ মিডিয়া প্রক্সি**: সরাসরি ফাইল লিংক এবং ক্যাশ নিয়ন্ত্রণ

### 🔊 পেশাদার ভয়েস সিন্থেসিস
- **Microsoft Edge TTS**: আবেগ-সচেতন Bengali ভয়েস (পুরুষ/মহিলা)
- **আবেগজনক SSML**: স্বয়ংক্রিয় গতি সমন্বয় (উত্তেজনা/দুঃখ)
- **৫-স্তর রিট্রাই লজিক**: নেটওয়ার্ক অস্থিরতার জন্য শক্তিশালী ত্রুটি পুনরুদ্ধার
- **খাঁটি MP3 আউটপুট**: ৪৮kbps - ৯৬kbps মনো ফরম্যাট

### 📲 Telegram ইন্টিগ্রেশন
- **স্বয়ংক্রিয় বিজ্ঞপ্তি**: প্রতিটি চ্যাট, বিশ্লেষণ এবং ভয়েস লগ ফরওয়ার্ডিং
- **ইমেজ প্রক্সি**: Drive ছবি সরাসরি Telegram-এ পাঠায় (লিংক নয়, আসল ফাইল)
- **আইডিয়াল লগিং**: দীর্ঘমেয়াদী অডিট ট্রেইল

### ⚖️ আইনি ও ধর্মীয় বিশ্লেষণ
- **Bangladesh Muslim Family Laws Ordinance 1961**: বিবাহ বৈধতা যাচাই
- **Child Marriage Restraint Act 2017**: বয়স-ভিত্তিক আইনি মূল্যায়ন
- **ব্ল্যাক ম্যাজিক (সিহর) স্বীকৃতি**: ইসলামিক লক্ষণ এবং রুক্ইয়া সুপারিশ

## 🚀 দ্রুত শুরু করুন

### প্রয়োজনীয়তা
- **Node.js** ≥ 18.x (ESM সমর্থন)
- **npm** বা **yarn**
- কমপক্ষে একটি AI API কী (নীচে দেখুন)

### ইনস্টলেশন

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/DADA310724/PARISA-AI.git
cd PARISA-AI

# নির্ভরতা ইনস্টল করুন
npm install

# পরিবেশ ভেরিয়েবল সেট করুন
cp .env.example .env
# আপনার API কী এবং সংজ্ঞা পূরণ করুন
```

### পরিবেশ কনফিগারেশন

```env
# 🤖 AI প্রোভাইডার (অন্তত একটি প্রয়োজন)
GEMINI_API_KEY=your-gemini-key
GEMINI_API_KEY_2=your-gemini-key-2
GROQ_API_KEY=your-groq-key
OPENROUTER_API_KEY=your-openrouter-key
DEEPSEEK_API_KEY=your-deepseek-key

# 🔗 Google Drive (স্ক্রিনশট ভিশন অ্যানালাইসিসের জন্য)
GOOGLE_SERVICE_ACCOUNT_JSON={
  "type": "service_account",
  "project_id": "...",
  "private_key_id": "...",
  ...
}

# 📊 Firebase (অপশনাল লগিং)
FIREBASE_DATABASE_URL=https://your-db.firebaseio.com

# 📱 Telegram (অপশনাল নোটিফিকেশন)
TELEGRAM_BOT_TOKEN=your-bot-token
TELEGRAM_CHAT_ID=your-chat-id

# 🌐 সার্ভার
PORT=3000
BASE_PATH=/
```

### চালু করুন

```bash
# ডেভেলপমেন্ট মোডে
npm run dev

# প্রোডাকশনে
npm start

# সার্ভার চেক করুন
curl http://localhost:3000/healthz
```

## 🔐 নিরাপত্তা মতামত

### API কী সুরক্ষা
- **`GOOGLE_SERVICE_ACCOUNT_JSON`** কখনো সোর্স কন্ট্রোল-এ কমিট করবেন না
- **Telegram টোকেন** ও **Firebase URL** পাবলিক উন্নতি রিপোজিটরিতে লিক করবেন না
- **প্রোডাকশনে**: মঞ্চ-ভিত্তিক নিরাপদ স্টোরেজ ব্যবহার করুন (AWS Secrets Manager, Google Secret Manager, etc.)

### ডেটা গোপনীয়তা
- **চ্যাট ডাটাবেস** ব্যক্তিগত তথ্য ধারণ করে — সার্ভার অ্যাক্সেস সীমিত রাখুন
- **Telegram ফরওয়ার্ডিং** সমস্ত ইন্টারঅ্যাকশন লগ করে
- **Firebase** ডেটা Google-এর ইউএস ডেটা সেন্টারে সংরক্ষিত হয়

### সিহর (ব্ল্যাক ম্যাজিক) সনাক্তকরণ

1. **হঠাৎ মনোভাব পরিবর্তন** — প্রেম → ঘৃণা (কোনো কারণ ছাড়াই)
2. **স্মৃতি অস্বীকার** — পুরনো প্রতিশ্রুতি ও ভালোবাসা সম্পূর্ণ অস্বীকার
3. **যোগাযোগ বিচ্ছিন্নকরণ** — হঠাৎ ব্লক বা নীরবতা
4. **পরিবার-প্রভাবিত আচরণ** — পিতামাতার কথায় অস্বাভাবিক দ্রুত পরিবর্তন
5. **ধর্মীয় আচরণ পরিবর্তন** — নামাজ-কালাম ছেড়ে দেওয়া

### ইসলামিক নিরাপত্তা (রুকইয়া শরীয়া)

যদি সিহর প্রভাব পাওয়া যায়, সিস্টেম সুপারিশ করে:

- **সূরা ফালাক** ও **সূরা নাস** — ফজর ও মাগরিবের পর ৩ বার
- **আয়াতুল কুরসি** — প্রতিটি নামাজের পর
- **সূরা বাকারাহ** — বাড়িতে শয়তান প্রবেশ রোধের জন্য
- **সিদর পাতা** — গোসলের জন্য মিষ্টি পানিতে সিদর পাতা রেখে

## 🐛 সমস্যা সমাধান

### সমস্যা: `msedge-tts not available`
**সমাধান**: `npm install msedge-tts@^2.0.5` চালান। এটি অপশনাল কিন্তু ভয়েস বৈশিষ্ট্যের জন্য প্রয়োজন।

### সমস্যা: Google Drive ফাইল 404
**সমাধান**: 
- `GOOGLE_SERVICE_ACCOUNT_JSON` সঠিকভাবে সেট করা আছে তা যাচাই করুন
- ফোল্ডার আইডি সঠিক তা নিশ্চিত করুন
- `/refresh-drive` এন্ডপয়েন্ট ম্যানুয়ালি ট্রিগার করুন

### সমস্যা: সমস্ত AI প্রোভাইডার রেট-লিমিটেড
**সমাধান**: আরও API কী যোগ করুন। এটি স্বয়ংক্রিয়ভাবে তাদের রোটেট করে।

### সমস্যা: মেমোরি বাইরে
**সমাধান**: `--max-old-space-size` বৃদ্ধি করুন:
```bash
node --max-old-space-size=512 server.js
```
